# Contribuindo para a documentação

Correções de documentação são bem-vindas quando explicam uma decisão, apontam fonte pública ou melhoram a clareza técnica. Não envie dados pessoais, credenciais, relatórios de segurança, conteúdo de formulários ou alegações sobre pessoas sem fonte verificável. Mudanças editoriais no produto são revisadas fora deste repositório.
