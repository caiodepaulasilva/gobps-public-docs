# Segurança

Não publique vulnerabilidades, credenciais, dados pessoais ou detalhes que possam ampliar risco operacional em issues públicas. Use o canal privado indicado no site para relatar um problema e inclua somente evidências necessárias para reprodução. O projeto não aceita submissões que exijam desativar controles de fonte, CORS, limite de chamadas ou validação de dados.
